# sporty.codes v21.7.3-P3 — Most Added to Elite bridge

- Elite Picks now derives live candidates from the same verified public-slip intelligence used by Most Added and Smart Board.
- Grades: Elite Strong, Elite Supported, Elite Watch.
- High popularity alone cannot create Elite Strong. Strong also requires independent booking codes, low opposition, valid odds, complete data and strong available statistical evidence.
- The generated `/data/elite-picks.json` feed remains supported and is merged with the live bridge.
- Elite cards can be added to the prediction slip, saved and shared.
- Custom SportyBet-backed API and collector are unchanged.
- No deposits, payments, withdrawals or real-money wagering features are included.
