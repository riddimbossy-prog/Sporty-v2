# Sporty.codes v21.6.1 — Phase 1 Popular Tips + Prediction Slip

Built on the working v21.5.3.1 collector.

## Smart Board

- Replaces the raw fixture wall with a one-column list of repeated popular tips.
- Defaults to **Today**.
- Supports Today, Tomorrow, Next 7 Days, All Available and Date Unavailable.
- Ranks publishable tips by slip appearances, share, distinct sources and Tip Strength.
- Excludes Avoid / No Pick rows from the public popularity list.
- Shows popularity, number of source slips and average odds.

## Prediction slip

- Round floating prediction-slip button.
- Button can be dragged around the screen and remembers its position.
- Add animation flies from the selected tip into the floating button.
- Internal slip drawer supports add, remove and clear.
- Combined odds calculator.
- **Practice points** and projected points only.
- No deposits, wallet, payment, withdrawal or real-money wager processing.
- Slip is saved locally on the current device.
- Branded share image includes up to four visible selections and a summary of the full slip.

## Date correction

- Rejects ancient dates produced by JavaScript parsing yearless strings such as `Wed 13 Feb` as February 2001.
- Supports Today, Tomorrow, numeric dates, timestamps and textual month dates.
- Public Code Hub kickoffs must fall within the near-term public-code window.
- Existing corrupt dates are hidden immediately.
- Run the Code Hub workflow once after deployment to refresh stored kickoff values.

## Infrastructure

- No Supabase migration.
- No Render Blueprint change.
- Existing GitHub Actions browser collector remains external to Render.
- PWA cache bumped to v21.6.1.
