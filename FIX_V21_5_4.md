# Sporty.codes v21.5.4 — Zero-result workflow fix

- A normal run with zero verified slips now finishes successfully.
- Nothing is published unless a slip contains verified selections.
- Missing secrets, Chromium crashes, collector exceptions, and Supabase failures still fail the job.
- Every run writes `collector-result.json` and uploads it as a seven-day GitHub Actions artifact.
- GitHub Step Summary shows outcome, verified slips, stored slips, and tip totals.
- Collector status distinguishes `verified`, `empty`, and `error` outcomes.
