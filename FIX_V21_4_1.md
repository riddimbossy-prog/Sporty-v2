# sporty.codes v21.4.2 — SportyBet schema parser hotfix

This hotfix fixes the silent zero-match response from the direct public SportyBet collector.

## Fixed

- Added live SportyBet aliases: `homeTeamName`, `awayTeamName`, `estimateStartTime`, `tournamentList`, `tournamentName`, `categoryName`, `eventStatusDesc`, market `desc`, and outcome `odd`.
- Added support for nested `data.tournamentList[].events[]` responses.
- Added 1X2 outcome-order fallback for three-way markets.
- Added safe source diagnostics: HTTP status, content type, response kind, JSON candidate count, top-level keys, and sample object keys.
- HTML, empty, and unrecognized JSON responses now surface as errors instead of silently returning `errors: []`.
- Smart Board now displays the real collector error when no fixtures are parsed.

No Supabase migration is required.
