# sporty.codes v21.7.3 — zero-result workflow regression fix

## Fixed

The v21.7.0 collector script still returned exit code 2 whenever a completed run produced zero verified slips. GitHub therefore marked a safe empty run as failed.

v21.7.3 restores the corrected behavior:

- an empty verified-slip run completes successfully with a warning;
- real collector errors, missing secrets, Chromium failures, and Supabase write failures still fail the workflow;
- every run writes `collector-result.json`;
- GitHub uploads the safe diagnostics file as an artifact;
- the workflow summary shows outcome, verified slips, stored slips, tips, and the last successful collection time.

No custom API, Smart Board, prediction-slip, Supabase schema, or Render Blueprint behavior changed.
